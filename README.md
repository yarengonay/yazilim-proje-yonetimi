# Yazilim Projesi Yonetim ve Maliyet Analizi

## Proje Hakkinda
15 gorevlik bir yazilim projesinin butce, sure ve kategori bazli
analizi Microsoft Excel kullanilarak yapilmistir.

## Kullanilan Fonksiyonlar
- XLOOKUP - Gorev bilgisi sorgulama
- SUMIFS - Kategori ve aya gore toplam sure
- COUNTIFS - Kosullu gorev sayimi
- FILTER - Kategoriye gore dinamik gorev listesi

## Dosya Icerigi
| Sayfa | Aciklama |
|-------|----------|
| Gorev Katalogu | 15 gorev, kategori, sure ve butce bilgileri |
| Zaman Kayitlari | 26 kayit, aylik calisma saatleri |
| Analiz | Dinamik sorgular ve kategori bazli maliyet |
| Yonetici Ozeti | Toplam butce, kritik gorev uyarilari |

## Proje Ozeti
- Toplam Butce: 31.850 TL
- Toplam Calisma: 154 saat
- En Yuksek Maliyet: Arama Algoritmasi - 2.800 TL
- Kategoriler: Frontend, Backend, Veritabani, Test, Tasarim
